## 2. 设计目标（验收阈值）

| 指标 | 目标 | 依据 |
|---|---|---|
| 第 1 关胜率 | ≥ 0.85 | 教学关，初始 3 只应稳过 |
| 第 2~4 关胜率 | 0.70 / 0.55 / 0.45（±0.15） | 难度递增，允许重复刷关补等级 |

| 近亲子代基因 | 比非近亲低约 5 | `inbreeding.genePenalty` |
| 近亲突变率 | 比非近亲高约 0.02 | `inbreeding.mutationBonus` |

### 2.1 技能节奏的解析结论（不依赖 core）

按冻结常量（初始精力 0、回合 +20、普攻命中 +10、上限 100）推：

- **小技能（45~50）不可能每回合放**：连续普攻后每回合净 +30；第 2 回合到 50 放一次小技能，
  下一次要再攒 2 回合（25→55），即约每 2 回合一次，上限 0.5 次/单位回合。
- **大招（70~80）约 3 回合一次**：全程普攻时精力 20 → 50 → 80，第 3 回合可放；
  放完回到 ≤10，再 3 回合回到 80。混入小技能会把间隔推到 4~5 回合。
- 因此当前技能成本（小 40~50、大 70~80）与 P-002 的目标一致；真实间隔由 `pnpm sim` 复核。

**死循环/负收益检查（静态）**

- 食物：满容量净 +4.4/h；即使 0 食物，产出仍在，饥饿只会降低效率，不会锁死（健康地板 1）。
- 金币：基础 +16.8/h；喂养 4 只约 4.8 金币/h（每小时 12 饥饿 ÷ 25/野果 × 10 金币），净正。
- 繁殖是主要金币/食物出口：按 2h 冷却连刷约 -50 金币/h，需要靠关卡重复奖励补；
  这是设计上的“主动支出”，不是死锁。
- 基因尘：产出 1.4/h + 五关 53 + 放生；2 级 20、3 级 60，均可达到。
- 设备上限：8h 离线约 134 金币 / 67 食物 / 11 尘，远低于上限。

## 5. 繁殖预期

| 项 | 值 | 来源 |
|---|---|---|
| 物种 | 父母 50/50 | DOMAIN §8.2 |
| 属性 | 父母 50/50，1% 突变到任意属性 | `mutation.elementChance` |
| 数值基因 | 父母均值 + Irwin–Hall(σ=8)，四舍五入并 clamp 0~100 | `mutation.geneSigma` |
| 特质突变 | 每次繁殖 3%（近亲 +2%） | `mutation.traitChance` |
| 性别 | 50/50 | DOMAIN §8.2 |
| 代数 | `max(父母)+1` | DOMAIN §8.2 |
| 近亲基因惩罚 | -5（四项各减，再 clamp） | `inbreeding.genePenalty` |
| 近亲冷却 | ×(1+0.2) | `inbreeding.fertilityPenalty`（P-017） |

预期：1000 次繁殖的四项基因均值应贴近父母均值（±3），标准差约 8；
近亲子代均值比对照低约 5，突变率约高 0.02。没有 NaN/Infinity、基因越界。

## 7. 交接与变更请求（给 A / 0）

1. **`TraitConfig.inheritance.weight` 未被消费**：DOMAIN §8.2 的特质突变是
   `rng.pick(availableTraits)` 均匀抽取。若希望 epic 更稀有，建议 A 在抽取时按
   `weight` 加权（或把 weight 改成“显性/隐性保留概率”并同步文档）。**不阻塞**。
2. **`hit` 与 `statMods` 语义冲突**：`hit` 基准 0、语义是加减修正，而 `statMods`
   是乘数。特质/被动目前都不修 `hit`；若以后要修，需要 A/0 决定是加性字段还是
   在 `deriveStats` 里特判。**不阻塞**。
3. **PvE setup 入口**：`buildBattleSetup(teams)` 要求双方都是 `PetInstance[]`，
   而 PVE 敌方由 `buildEnemyTeam(stage)` 返回 `BattleUnitInit[]`。sim 目前用
   `buildBattleSetup([pets, pets]).teams[0]` 取玩家侧，属于临时拼法。建议 A 提供
   “玩家侧 init”或允许 `buildBattleSetup` 接受单边队伍；**不阻塞**。
4. **没有 Profile 工厂**：sim 按 `Profile` 类型构造字面量。若 A 给 `Profile` 增加
   必填字段，请通知 D 同步 `packages/sim/src/fixtures.ts`。
5. **数值仍需实测**：本文所有“预期”在 `pnpm sim` 跑出真实数据后以自动段落为准；
   D 只调 JSON，不改常量与公式。
