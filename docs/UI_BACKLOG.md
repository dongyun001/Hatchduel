## 0. 现在（M2 UI 开工前必须做）

这些不改变玩法，但会决定 PvP/排行页面是否可维护，归 B 的 M2 第一批。

| # | 项 | 验收 |
|---|---|---|
| UI-01 | **UI kit 抽组件**：Button（主/次/危险/禁用）、Panel、Modal/Confirm、Toast、Tag、ResourceBar、PetCard、Loading | 新页面不新增重复按钮/弹窗实现；旧页面逐步替换 |
| UI-02 | **三态统一**：Loading / Empty / Error（含错误码文案、重试按钮） | 每个列表与详情页都有三态；错误码走 `services/errors.ts` |
| UI-03 | **安全区与横屏**：刘海/圆角/底部手势区；640×360 逻辑分辨率下不被裁切 | 真机/模拟器截图无遮挡；`SafeArea` 组件被所有页面使用 |
| UI-04 | **构建配置固定（P-123）**：横屏 orientation、AppID、`urlCheck` 不再靠构建产物手改 | 构建脚本或 `game.json` 模板固定；重新构建后参数不漂移 |
| UI-05 | **列表虚拟化**：宠物列表 ≥40 时不一次性实例化 | 列表滚动稳定；节点数受控 |
| UI-06 | **宠物改名 UI**：PetDetail 支持改名（12 字上限、非法字符提示） | 调 `/pets/:id/rename`，成功后本地档同步 |
| UI-07 | **独立编队页**：从 StageSelect 里拆出可复用的编队编辑（PvE 与 PvP 进攻共用） | 编队改动不依赖进入关卡 |
| UI-08 | **错误态运行时覆盖**：`PET_IN_USE`（编队/防守分支）、`BATTLE_NOT_FOUND`、`VALIDATION_FAILED` | devFaults 或真实构造，各出现一次可读提示 |
| UI-09 | **图标/占位规范**：32/48 图标、96 战斗精灵、256 立绘的占位图统一命名与 pivot | 新页面直接用；不出现拉伸/模糊 |

## 1. M2（异步 PvP 与排行榜）

依赖 `contract-v1.6`（`docs/CONTRACT.md` §7.5）；接口未上线时用 mock + devFaults 先跑通交互，再切真实接口。

| # | 页面/能力 | 要点 | 验收 |
|---|---|---|---|
| M2-01 | **PvP 入口**（Home） | 显示段位、当日剩余次数、防守状态（未设置/已设置/stale） | 数据来自 `/profile` + `/pvp/defense`；未设置时引导 |
| M2-02 | **防守设置页** | 1~3 只、非蛋；展示快照时间与 24h 有效期；`stale` 提示重新设置 | 调 `POST /pvp/defense`；成功后刷新 profile；放生被 `PET_IN_USE` 拒绝有文案 |
| M2-03 | **对手/匹配页** | 对手展示名称、段位、物种预览、平均等级、`isBot` 标记；显示剩余次数；刷新重新匹配 | 调 `GET /pvp/opponent`；机器人明确标注“训练师”；自己不会出现 |
| M2-04 | **战斗结果页** | 攻方视角胜负/平、回合数、双方 rating 变化、`replayId`；失败/次数用尽/对手不可用有分支 | 调 `POST /pvp/fight`；409/429/410 按错误码展示；幂等重试不重复扣次数 |
| M2-05 | **战报回放页** | 只播 `events`，支持播放/暂停/倍速/跳到结算；显示双方名称与 rating | 调 `GET /pvp/replay/:id`；不重新模拟、不覆盖结果；过期显示 `REPLAY_EXPIRED` |
| M2-06 | **排行榜页** | 四个 tab（段位/图鉴/最佳基因/世代）；前 N + 自己；`selfEligible=false` 时显示“完成一场 PvP 后上榜” | 调 `GET /leaderboard`；无机器人；切换 tab 不串数据 |
| M2-07 | **新错误码文案** | `DAILY_LIMIT_REACHED`、`OPPONENT_UNAVAILABLE`、`REPLAY_EXPIRED` | `verify-errors.ts` 覆盖；运行时各出现一次 |
| M2-08 | **PvP 本地态** | 请求中禁用重复点击；409 重建；`serverTime` 偏移；断网重试 | 与现有 Habitat/StageSelect 的写法一致 |
| M2-09 | **计时/沉浸** | 回放与排行榜不阻塞主循环计时；离开页面不丢本地档 | 与 M1 计时口径一致 |

## 3. 已知问题（持续跟踪）

- `client/build/**` 是本地产物，不可作为基线；真机包里的旧 IP/AppID 不要复用。
- 场景是手写 JSON，后续用 Cocos 编辑器保存时注意不覆盖脚本引用。
- 列表虚拟化、独立编队页、改名 UI 在 M2 之前属于欠账，不要在新页面复制旧的临时写法。
- 新增协议字段后先跑 `node client/tools/sync-lib.mjs`，再跑 `typecheck.mjs`。
