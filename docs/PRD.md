## 1. 产品定位

### 1.1 一句话描述

一款以**圈养、繁殖、基因收集**为核心的宠物养成游戏；战斗是核心玩法之一；异步联机贯穿收集与对战；微信小游戏首发，后续登陆 Steam。

### 1.2 品类与关键词

养成模拟、宠物收集、繁殖/基因、轻策略回合制、放置留存、异步 PvP、跨平台。

### 1.3 不是什么

- **不是纯放置挂机**：离线产出是留存层，不是全部。战斗和收集不能被稀释。
- **不是即时动作对战**：战斗为回合制，不做帧同步格斗。
- **不是单机闯关游戏**：联机是核心卖点，账号、云存档、异步 PvP 从第一版就要有。
- **不是抽卡游戏**：MVP 不做抽卡，宠物来自初始、关卡、繁殖和活动。

### 1.4 平台策略

| 阶段 | 平台 | 说明 |
|---|---|---|
| 首发 | 微信小游戏 | 横屏；审核快、传播方便；需要类目/资质 |
| 后续 | Steam（Windows） | 桌面端；离线可玩；Steam 云存档、成就 |
| 设计目标 | 同一账号跨端 | 微信 openid 与 Steam ID 绑定到同一账号；存档以服务器为准 |

### 1.5 商业模式

**Demo 免费**，正式版商业模式待定（买断/广告/IAP）。Demo 阶段不做付费点，避免合规和数值复杂度；正式版模式在 M2 前定。它会影响版号、随机抽取公示、资源产出和服务器成本。

## 2. 目标用户与核心体验

### 2.1 目标用户

- 喜欢宠物收集、繁殖、养成的休闲玩家
- 喜欢轻度策略对战、但不追求操作和反应的玩家
- 碎片时间上线收菜，长线追求稀有后代和图鉴的玩家
- 微信小游戏与 Steam 的轻度模拟经营用户

### 2.2 三种核心体验

1. **养出来**：看着宠物从蛋到成年，状态、成长、栖息地都有反馈。
2. **配出来**：通过繁殖得到更好的基因、稀有特质、意外的属性组合。
3. **打出来**：用自己养出来的队伍去 PVE/PvP，验证养成成果。

### 2.3 时长设计

- 单场战斗：2~5 分钟
- 日常在线：10~20 分钟（收菜、照料、繁殖、打一两场）
- 长线目标：以天/周计（世代、图鉴、赛季）
- 离线：默认最多 8 小时收益，避免“必须每小时上线”

## 3. 核心循环

### 3.1 主循环

```
        ┌────────────────┐
        │   圈养 / 产出   │
        └───────┬────────┘
                │ 金币、食物、基因尘
                ▼
        ┌────────────────┐
        │ 喂养 / 照料 / 成长 │
        └───────┬────────┘
                │ 成年、状态良好
                ▼
        ┌────────────────┐
        │   繁殖 / 基因    │
        └───────┬────────┘
                │ 新个体、稀有特质、突变
                ▼
        ┌────────────────┐
        │ 战斗 / PvP / 排行 │
        └───────┬────────┘
                │ 资源、稀有材料、段位
                └──────────► 回到圈养
```

**一句话**：圈养产出资源 → 喂养成长 → 繁殖更强或更稀有的个体 → 战斗/PvP 获取资源与稀有基因 → 扩建栖息地、继续繁殖。

### 3.2 次级循环

- **日常循环**：上线收菜 → 照料 → 繁殖/孵化 → 打一场 → 下线。
- **收集循环**：物种 × 属性的图鉴、稀有特质、最佳基因记录。
- **赛季循环**：异步 PvP 段位、排行榜、赛季奖励。
- **社交循环**：好友互访、互助、后续的交易。

### 3.3 设计原则

1. **单机可玩，联网优先**：离线也能照料和 PVE；账号、云存档、异步 PvP 是核心能力。
2. **时间是一等公民**：成长、繁殖、产出、离线收益都由时间驱动，服务器可校验。
3. **数据驱动**：物种、属性、相性、克制、技能、特质、栖息地、食物、关卡、经济全部配置表。
4. **服务器权威**：货币、宠物、繁殖、战斗结果不能由客户端直接决定。
5. **逻辑与表现分离**：领域与战斗核心是纯 TS，不依赖 Cocos/微信/Steam，可被服务器复用。
6. **原创 IP**：不使用任何已有作品的宠物形象、名称和美术。

## 4. 系统总览与权重

| 系统 | 要解决的问题 | MVP 深度 | 后续 |
|---|---|---|---|
| 圈养 | 日常上线理由、资源产出、宠物状态 | 1 个栖息地、4 个位置、3 项需求 + 健康、离线 8h | 多栖息地、装饰、环境事件 |
| 繁殖 | 长线追求、基因深度、稀有度 | 双亲、蛋、遗传、突变、近亲惩罚、代数 | 杂交物种、血统图、交易 |
| 战斗 | 养成验证、PVE 内容、PvP | 3v3 回合制、5 关 PVE、AI、自动战斗 | 更多关卡、技能升级、赛季规则 |
| 联机 | 核心卖点、留存、社交 | 账号、云存档、异步 PvP、排行榜 | 好友互访、赛季、交易、实时房间 |
| 收集/图鉴 | 目标感、稀有度 | 5 物种 × 5 属性图鉴、剪影（25 组合） | 25 组合全收集、成就 |
| 放置/增量 | 留存、离线价值 | 离线产出、栖息地升级 | 受控的数值成长、装饰 |
| 经济 | 资源循环、付费 | 3 种软资源、消耗闭环 | 付费货币、活动经济 |

> 权重是**设计注意力**，不是开发工时比例。优先级：圈养/繁殖 > 联机 > 战斗 > 收集 > 放置。

## 5. 宠物模型

### 5.1 宠物 = 物种 × 属性

每只宠物由两个静态维度定义，再加上个体基因与状态。

| 维度 | 说明 | 决定什么 |
|---|---|---|
| **物种** | 龟、鱼、青蛙、猫、蛇（MVP 5 种） | 基础属性、物种技能、被动、物种克制、栖息地偏好 |
| **属性** | 水、火、草、土、雷 | 可携带的属性技能、属性特效、与物种的相性、栖息地加成 |

> **后续物种**：恐龙、鼠、象、河马、鸟。暂不进入 MVP，保留配置位与图鉴剪影，后续版本再扩。

同一物种可以搭配不同属性。例如“水龟”和“土龟”是两只不同的宠物，相性也不同。

### 5.2 相性（属性 × 物种）

| 相性 | 效果（战斗创建时生效） |
|---|---|
| 契合 | 全基础属性（HP/ATK/DEF/SPD）+10% |
| 普通 | 无修正 |
| 冲突 | 全基础属性 -10% |

示例：水 × 龟 = 契合；雷 × 鱼 = 契合；火 × 鱼 = 冲突；土 × 蛇 = 契合。

相性让繁殖有取舍：同样是鱼，水鱼比火鱼更强；冲突组合通常出现在繁殖失误、敌方或特殊关卡里。

### 5.3 物种克制（单向）

| 攻方物种 | 克制对象 | 依据 |
|---|---|---|
| 猫 | 蛇 | 猫斗蛇 |
| 蛇 | 鱼 | 水蛇捕鱼 |
| 鱼 | 青蛙 | 鱼食蝌蚪 |
| 龟 | 鱼 | 龟捕鱼 |
| 青蛙 | —— | 控制原型，无克制对象 |

- 攻方克制守方：伤害 ×1.25
- 攻方被守方克制：伤害 ×0.85
- 无关系：×1.0
- 不要求对称（猫克蛇，蛇不克猫）
- 猫、龟无天敌（刺客/坦克原型）；鱼被蛇和龟两个物种克制
- **初版克制网，以 sim 报告为准微调**

### 5.4 个体与基因（新增）

战斗和繁殖使用的是**个体**，不是静态配置。每只个体包含：

| 字段 | 说明 |
|---|---|
| 唯一 ID | 全局唯一，用于存档、战斗、交易 |
| 物种 / 属性 | 决定基础属性、技能池、相性、克制 |
| 基因 | HP/ATK/DEF/SPD 四项基因，0~100 |
| 特质 | 已表达特质、隐性特质；影响属性或产出 |
| 性别 | 公/母；繁殖用 |
| 代数 | 父母代数最大值 +1 |
| 父母与祖先 | 用于近亲检测和血统展示 |
| 年龄阶段 | 蛋、幼年、成年、老年 |
| 状态 | 饥饿、心情、清洁、健康 |
| 等级/经验 | 经验只来自 PVE 战斗；等级提升基础属性 |
| 繁殖状态 | 可繁殖时间、冷却 |

属性不是配置值直接决定，而是按固定顺序计算：

```
最终属性 = 物种基础
         × 等级成长
         × 基因质量
         × 年龄阶段
         × 状态
         × 特质
         × 被动
         × 相性
```

每一步的系数、取整顺序和边界见 `DOMAIN_MODEL.md`。**全程浮点，最后一次性 floor**，保证跨端一致。经验只来自 PVE 胜利，升级曲线与关卡经验见 `DOMAIN_MODEL.md` §2.7.1。

### 5.5 获取途径（MVP）

| 途径 | 内容 |
|---|---|
| 初始 | 水龟、雷鱼、草蛙 |
| 关卡首通 | 第 2 关给火猫；第 4 关给土蛇 |
| 繁殖 | 物种来自父母之一，属性来自父母之一，小概率突变 |
| 活动/后续 | 限时蛋、图鉴奖励、PVP 赛季 |

不做抽卡。**火鱼（冲突）可以作为繁殖教学**：玩家用雷鱼（鱼/雷）× 火猫（猫/火）繁殖，子代可能抽到“鱼 + 火”，得到冲突的火鱼，直观理解相性代价。

> **初始保底**：3 只初始宠物保证至少 1 公 1 母，且直接为成年，确保玩家当天能完成第一次繁殖。后续获得的宠物按正常阶段（蛋/幼年）走。

### 5.6 图鉴与稀有度

- 图鉴按“物种 × 属性”记录：未见过（剪影）、已见过、已拥有、最佳基因。
- 5 物种 × 5 属性 = 25 个组合；MVP 实际可获得约 5~10 个。
- 稀有度来自：稀有特质、高基因、稀有属性组合、高代数。MVP 不做独立稀有度星级。

## 6. 圈养

### 6.1 栖息地

- MVP 1 个栖息地，4 个位置；后续可扩建、装饰、分属性区域。
- 栖息地有**属性倾向**（水/火/草/土/雷），匹配的宠物产出加成。
- 产出：金币、食物、基因尘（按配置的速率）。
- 升级：提高容量、产出、离线上限；消耗金币和基因尘。

### 6.2 需求与状态

| 状态 | 范围 | 影响 | 恢复方式 |
|---|---|---|---|
| 饥饿 | 0~100 | 低饥饿降低产出和战斗属性 | 喂食 |
| 心情 | 0~100 | 低心情降低暴击和产出 | 玩耍、装饰 |
| 清洁 | 0~100 | 低清洁降低健康和产出 | 清理 |
| 健康 | 0~100 | 低健康降低全属性；地板 1，不死亡 | 饥饿/清洁均 ≥50 时自然恢复（速率初版，待 sim 验证） |

- 状态随时间衰减；离线也衰减，但有上限，避免“上线全死”。
- 状态参与属性计算，让“照料”有实际收益。
- **不做主动治疗**；健康不消耗金币，只在饥饿/清洁都达标时自然恢复。

### 6.3 产出

- 每 10 分钟结算一次（服务端/客户端按时间戳插值）。
- 产出 = 基础速率 × 属性匹配 × 阶段 × 心情 × 容量利用率。
- 离线收益最多 8 小时；超过部分不累积。
- 食物不足时，饥饿下降更快，产出降低。

### 6.4 成长

| 阶段 | 进入条件 | 特点 |
|---|---|---|
| 蛋 | 繁殖产生 | 不产出、不战斗；孵化计时 |
| 幼年 | 孵化后 | 属性 70%，不可繁殖 |
| 成年 | 幼年结束 | 100%，可繁殖 |
| 老年 | 成年若干天 | 属性 90%，繁殖力下降，产出略降 |

MVP 计时（可配置）：孵化 30 分钟、幼年 2 小时、成年 7 天后进入老年。不实现死亡。

### 6.5 交互

- 点击/拖拽喂食、清理、玩耍；显示状态条和提示。
- 宠物列表显示状态异常图标，一键跳转。
- 战斗前提示“状态不佳会降低属性”。

## 7. 繁殖

### 7.1 条件

- 双方成年、可繁殖时间已到、不在冷却
- 性别不同（MVP 固定公/母；后续可扩展）
- 不是同一只个体
- 支付繁殖成本（金币 + 食物）
- 栖息地或蛋栏有空位

### 7.2 流程

```
选择双亲 → 预览（不显示精确结果，只显示区间与风险）
→ 确认并支付 → 产生蛋（孵化 30 分钟）
→ 领取 → 幼年 → 成年
```

### 7.3 遗传规则（MVP）

| 项 | 规则 |
|---|---|
| 物种 | 从父母中随机继承一个（50/50） |
| 属性 | 从父母中随机继承一个（50/50）；1% 概率突变为随机属性 |
| 数值基因 | 双亲基因均值 + 随机波动 + 突变，限制 0~100 |
| 特质 | 父母已表达/隐性特质参与遗传；显性表达；3% 概率突变出新特质 |
| 性别 | 随机 |
| 代数 | max(父母代数) + 1 |

具体算法、显隐性模型和近亲判定见 `DOMAIN_MODEL.md`。

### 7.4 近亲

- 共同祖先在 3 代以内 → 判定为近亲。
- 近亲惩罚：子代基因 -5、突变率 +2%、子代繁殖力 -20%。
- UI 必须明确警告，不能隐藏。

### 7.5 冷却与寿命

- 繁殖后冷却 2 小时。
- 老年繁殖力 50%（体现为冷却延长）。
- **宠物不会死亡**；MVP 不实现寿命。玩家可以主动放生。

### 7.6 放生

- 蛋不可放生；锁定、上阵、栖息地中的不可放生。
- 至少保留 1 只成年宠物，避免无法战斗/繁殖的软锁。
- 放生返还基因尘，按等级、基因总和、特质稀有度计算；公式见 `DOMAIN_MODEL.md`。
- 放生不可撤销；图鉴保留“已拥有”记录。
- 服务器写审计日志，防止刷资源。

### 7.7 UI 要点

- 双亲槽位、相性/克制提示、基因区间、近亲警告、成本。
- 结果揭晓有“开蛋”演出，强调期待感。
- 图鉴记录最佳基因和稀有特质。

## 8. 战斗

### 8.1 形式

- 3v3 回合制，双方各上阵 3 只。
- 行动顺序按 SPD 从高到低；同速用**中立规则**（按队伍交替或种子决定），不能固定 0 队先手。
- 30 回合上限，未分胜负判平局；PVE 平局视为失败，可重试。
- 单场目标 6~12 回合。

### 8.2 精力

| 项 | 数值 |
|---|---|
| 上限 | 100 |
| 初始 | 0 |
| 每回合开始 | +20 |
| 普攻命中 | +10 |
| 小技能 | 40~50 |
| 大招 | 70~80 |

> 旧版“小技能 30~40”会导致每回合都能放，精力系统失效；v1.0 统一为 40~50。

### 8.3 伤害公式

```
命中率 = clamp(基础命中 + 命中修正 - 目标闪避, 5%, 100%)
暴击判定 = random() < 暴击率

基础伤害 = ATK × 技能倍率 × K / (K + DEF)        # K = 400
物种克制：×1.25 / ×0.85 / ×1.0
最终伤害 = 基础伤害 × 暴击倍率 × 克制倍率 × 随机浮动(0.95~1.05)
```

- 暴击伤害统一 150%（可被特质调整）。
- 相性不参与伤害乘算，在战斗创建时修正基础属性。
- 技能倍率：普攻 1.0；小技能 0.9~1.2；大招 1.6~2.0；物种技能 1.0~1.5 或纯功能。
- 全程浮点，最终 floor。

### 8.4 状态效果

单体/群体伤害、治疗、护盾、攻击/防御/速度增减、眩晕、沉默、减速、灼烧/中毒（持续伤害）、驱散。

- 同类 buff 不叠加，只刷新时长与数值（取更强）。
- 眩晕跳过行动，当回合消耗。
- DOT 在回合开始结算，不占行动。

### 8.5 AI 与自动战斗

- 敌人 AI 与“自动战斗”共用一套确定性策略。
- 优先级：能放大招 → 放；能放群体/强效果小技能 → 放；否则普攻。
- 目标：优先被自己物种克制的敌人，其次血量比例最低，最后用种子随机。
- 自动战斗 = AI 替玩家提交指令，不走捷径。

### 8.6 PVE

- MVP 5 关，线性解锁；第 5 关为 Boss。
- 敌方带等级和基因质量，随关卡递增。
- MVP 敌方阵容只使用 5 个 MVP 物种；具体关卡配置与数值由 sim 调参后填入（初版）。
- 首通奖励：宠物、蛋、资源；重复挑战给少量资源。
- 失败/平局可无限重试。
- 宠物经验仅来自 PVE 胜利：首通 `30 + 关卡序号×10`，重复为首通的 1/3；异步 PvP 不给经验（初版，待 sim 验证）。

### 8.7 战斗输入

- 战斗使用**个体快照**：等级、基因、特质、状态、技能。
- 状态差会降低属性，这是圈养与战斗的连接点。
- 联机战斗服务器权威；PVE 可以本地计算，但奖励由服务器校验幂等。

## 9. 联机（核心卖点）

### 9.1 原则

1. **异步优先**：先做异步 PvP、排行榜、好友互访，再做实时房间。
2. **服务器权威**：客户端只提交动作，不提交结果。
3. **跨平台账号**：微信和 Steam 绑定到同一账号，存档以服务器为准。
4. **单机可玩**：Steam 允许离线玩，联网后同步并校验。

### 9.2 阶段

| 阶段 | 内容 | 为什么 |
|---|---|---|
| Phase 1（MVP-B） | 账号、云存档、异步 PvP、排行榜 | 联机核心价值，成本可控 |
| Phase 2 | 好友互访、赛季、受限交易、公会 | 社交与长线 |
| Phase 3 | 实时好友房间（回合制） | 需要在线人数和运维 |

### 9.3 为什么不是实时优先

- 冷启动：玩家不够时匹配不到人。
- 运维：实时房间需要长连接、超时、重连、反作弊。
- 收益：异步 PvP 已经能提供“用别人的队伍打”的核心体验。

### 9.4 异步 PvP

- **Phase 1 异步 PvP 为服务器全自动结算：双方均由 AI 按确定性策略行动，攻方观看战报，不做手动操作。**
- 玩家设置 3 只防守队伍，服务器保存快照（24 小时有效）。
- 匹配对手 → 服务器用同一战斗引擎模拟 → 返回战报回放 → 更新段位。
- 客户端只上传阵容，不决定结果。

### 9.5 跨端与离线

- 账号：平台无关的 `accountId`，绑定微信 openid / Steam ID。
- 云存档：服务器为唯一权威；客户端本地缓存。
- Steam 离线：本地推进，联网后按时间戳和服务端校验合并；超额收益封顶。

### 9.6 社交

- 排行榜：段位、图鉴、最佳基因、世代。
- 好友互访：查看栖息地、每日互助/偷取有上限。
- 交易：Phase 2 再开，需绑定、每日限额、税、反 RMT。

详细协议、接口和反作弊见 `ONLINE_DESIGN.md`。

## 10. 放置/增量

- 离线产出是留存层，不是核心玩法。
- 栖息地升级采用递增成本，避免线性滚雪球。
- **不做转生/威望重置**；世代只作为血统与收集维度，高世代解锁稀有特质/外观，但不重置进度、不直接碾压低世代。
- 防作弊：离线收益封顶、服务器时间、异常检测。
- 不做无限指数通胀；所有产出有上限和消耗出口。

### 12.3 桌面端（Steam）

- 指针悬停显示 tooltip；更大的信息密度。
- 支持窗口化和全屏；不强制联网。
- 快捷键：空格继续、Esc 返回。

### 12.4 移动端

- 横屏；安全区适配；点击目标足够大。
- 单手可完成日常操作。

## 13. MVP 范围

MVP 拆成三个可验收阶段，避免“一次做完”。

### 13.1 MVP-A：单机垂直切片

- 1 个栖息地、4 个位置
- 3 只初始宠物（水龟、雷鱼、草蛙）
- 喂养、清洁、玩耍、状态、成长阶段
- 放生（基础规则与返还）
- 1 次完整繁殖（含蛋、孵化、遗传）；近亲检测已接入，可用调试构造验证
- 离线收益（8 小时上限）
- 1 场 3v3 战斗（含 AI、自动、日志）
- 本地存档 + 云存档接口预留
- **验收**：新玩家 30 分钟内完成“收菜→喂养→繁殖→战斗”主循环；含孵化的完整切片在 60 分钟内可验证（孵化可离线等待）。

### 13.2 MVP-B：联机核心

- 账号（微信登录/游客/绑定）
- 云存档（服务器权威）
- 异步 PvP（防守队伍、匹配、模拟、战报）
- 排行榜（段位）
- **验收**：两个账号能互相打异步 PvP，战报可回放，段位变化正确。

### 13.3 MVP-C：微信首发版本

- 5 个物种、5 个属性配置（后续再扩）
- 技能：普攻 1 + 属性技能 10（5 属性 × 2）+ 物种技能 5 + 被动 5（16 主动 + 5 被动）
- 特质：15~20 条（普通/稀有/史诗）
- 5 关 PVE（含 Boss），首通给火猫/土蛇
- 1 个栖息地、4 个位置、升级
- 繁殖完整（突变、近亲、代数）
- 图鉴（5×5，实际可获得约 5~10）
- 基础 UI、BGM 1 首、关键音效
- 云存档、异步 PvP、排行榜
- **验收**：微信审核通过，冷启动可玩，核心循环闭环。

### 13.4 MVP 明确不做

实时房间、交易、公会、抽卡、付费货币、赛季、宠物死亡、转生/威望、杂交物种、25 组合全收集、Steam 发行（M4）、回放 UI（数据层有）。

## 15. 非功能需求

- **性能**：微信主包内部预算 ≤2MB（官方上限 4MB）；总资源内部预算 ≤15MB（官方上限以最新规则为准）；首屏 ≤3 秒（4G 中端机）；战斗单回合 ≤50ms；UI 60fps。
- **兼容**：微信最新版 iOS/Android；Steam Windows 10+；横屏。
- **语言**：MVP 仅简体中文；所有文案外置，预留多语言。像素风 UI 的中文正文用系统字体，避免低分辨率像素字不可读。
- **离线**：Steam 核心循环可离线；微信 PVE 可本地，云功能需联网。
- **稳定**：存档损坏可回退；崩溃可上报；战斗异常不崩。
- **可调试**：跳过战斗、加资源、一击必杀（仅开发构建）。
- **可扩展**：新增物种/属性/特质/关卡只改配置。
- **可观测**：关键埋点（留存、循环完成率、繁殖次数、PvP 参与率）。

## 16. 合规与风险

### 16.1 合规

- **微信小游戏**：主体、类目、软著、版号/备案、实名与防沉迷；以微信最新规则为准，M2 前落实。
- **随机繁殖**：如果涉及付费随机，需要概率公示；MVP 免费繁殖也要在 UI 说明概率。
- **交易/虚拟物品**：Phase 2 的交易可能涉及虚拟物品交易红线，需提前评估。
- **Steam**：全球版与蒸汽平台规则不同；隐私政策、退款、地区限制。
- **数据**：未成年人信息、账号注销、数据导出。

### 16.2 风险

| 风险 | 影响 | 对策 |
|---|---|---|
| 范围爆炸 | 延期、做不完 | 先做深一个循环；MVP 三段拆分 |
| 联机冷启动 | 匹配不到人 | 异步优先；排行榜/好友补足 |
| 经济通胀 | 数值失控 | 产出入上限、消耗出口、模拟调参 |
| 跨端存档冲突 | 丢档/复制 | 服务器权威 + revision + 审计 |
| 客户端作弊 | 经济崩坏 | 服务器校验、时间戳、幂等、异常检测 |
| 美术成本 | 延期 | M0 定规格、占位图先行、按包体预算 |
| 单人运维 | 客服/服务器压力 | 云托管、自动化、先小规模 |
